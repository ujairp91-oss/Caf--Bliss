
#  Cafe Bliss – Cafe Management System

##  About the Project
Cafe Bliss is a multi-page Cafe Management System website developed as a college mini-project using HTML5 and CSS3.

The website provides an attractive interface for exploring cafe information, menu items, food images and table booking details.

##  Features
- Home Page
- About Us Page
- Menu Page
- Gallery Page
- Booking Page
- Contact Page
- Order Enquiry Form
- Confirmation Page
- Attractive CSS Styling

##  Technologies Used
- HTML5
- CSS3

##  Project Pages
- index.html – Home Page
- About.html – About the Cafe
- Menu.html – Cafe Menu
- gallery.html – Image Gallery
- booking.html – Booking Page
- contact.html – Contact Page
- confirmation.html – Confirmation Page

##  How to Run
1. Download or clone this repository.
2. Open the project folder.
3. Open index.html in your web browser.
4. Explore the Cafe Bliss website.

##  Project Limitations
This is a frontend demonstration project. It does not include actual online payments, database storage, user authentication or confirmed online orders.
